### Method notes that bind the evidence below

- **Nothing was taken on trust from a prior record.** Run 2's report was read for its *shape* — the
  measurement module and the mutation anchors it designed — and every one of those was re-verified
  against this tree (each anchor asserted to occur exactly once) and re-run here. No number, trace or
  classification is carried over.
- **A caution about the carried harness, found by running it.** Two copies of run 2's measurement
  module are saved beside its evidence, and **they are not the same file**:
  `~/tactus-artifacts/g4b-evidence-81ee09ef/g4b_meas.rs` is an earlier draft whose `G4A3` asserts a
  three-lineage publication list, and `recover-tests-with-g4b-module.rs` is the file that produced run
  2's report, whose `G4A3` asserts the two-lineage list, the first step dispatching the survivor's
  repair, and the newer lineage's integration starting only at s5. The draft fails on this range at
  its own assertion (`meas-run1.log`), because three lineages never publish in that fixture — the
  third meets a real conflict. **The module used here is the one extracted from
  `recover-tests-with-g4b-module.rs`**, renamed `g4r3_meas`; `meas-run1.log` is kept as the record of
  the draft, and `meas-run2.log` is the run this report quotes. Recorded because a successor reaching
  for the same harness will otherwise reach for the wrong file.
- **Mutation is the detection test.** A green suite proves the tests pass, not that they still
  detect. Every "test X guards Y" claim below is backed by a mutation of Y observed here to kill X.
  Every mutation ran against the **full** library suite (§3), never a subset.
- **The measurement code is temporary and uncommitted.** Seventeen measurement tests plus one
  ignored subprocess helper (`g4r3_*`) were appended to `src/engine/topology/recover/tests.rs` for
  this run, with the same `three_tasks` flag on the recover fixture run 2 added; read-only
  `eprintln!` probes were added to the two samplers and to the per-element residue test and then
  removed. Every file so edited was restored from a `cp` backup and hash-verified against `HEAD`
  before the report head was built (§1). Their source and every log are kept beside this report's
  evidence.
- **Every live/durable comparison is live against durable.** `live_equals_replay` compares the
  stepped `TopologyRun`'s own fold (`run.fold().state()`) against a fresh replay of the bytes read
  back from `events.jsonl`; `replay_twice_equal` is printed beside it and is the weaker claim.
- **Restores use `cp`, never `git checkout --`.** The measurement module is uncommitted, and a
  `git checkout --` of a file carrying it would have destroyed it silently.
- **Nothing this run constructed is committed, and this report proposes committing none of it.**
  A gate reports; it does not land code. The commit that carries this report changes
  `reviews/` and nothing else: `git status --short` and `git diff --stat HEAD` were read
  immediately before it and every path was under `reviews/`, and the files were staged **by
  explicit path**, never `git add -A`, so that a mutation or a planted probe left behind could not
  ride along. The one construction a successor would benefit from committing — the measurement
  helpers `drive_keep` and `live_vs_replay`, and a counting question-id source for the driven
  recover fixture — is a **recommendation for a later pull request** (§13, §11 O2), deliberately not
  made here, and the gate's evidence does not depend on it: every value this report quotes was
  produced by running the construction, and the construction's source is preserved beside the
  evidence so anyone can re-run it.
- **Verify by hash, not by line count.** The mutation driver asserts each anchor occurs exactly
  once, that each mutated file's hash differs after the edit, and that it equals the pre-mutation
  hash again after the restore, before the next mutation.

1. **It rests on the owner's two inherited P1 deferrals.** `PR8-R2-SPEND-REPLAY` and
