## 4. Readings this triage adds

- **R21 (withdrawn).** The claim that the `effects` census covers PR8's kill and residue
  obligations is withdrawn; the recovery tests of F9 carry them.
- **R22 — spend on replay.** The unavailable terminals carry no review record, so an integration
  review that ended in `HumanRequired` or an infrastructure outage is charged live and not on
  replay. The ceiling is therefore checked against a live total that is never below the replayed
  one. Recorded in `pr8-plan.md`.
- **R23 — the authorized head with no transaction open.** The latest `task_merged.merged_sha` in
  the proven prefix; before any publication, the recorded base. A ref elsewhere, or absent after a
  publication, is foreign integration state and refuses (`[T-RESUME].refusal_condition`).
- **R24 — which verification errors are outages.** A Runner error spawning a gate is
  `Infrastructure{RunnerSpawnFailure}` (INV-23); a reviewer's process failure already reaches the
  terminal as `ReviewUnavailable` through `run_review`; every other error from the verification
  (a containment refusal, a Git error inspecting the repository) is a defect of the run, not an
  outage, and ends the command resumably as before. Deferral is never applied to an error the
  contract does not classify as infrastructure.
